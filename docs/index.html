📘 Overview

Geotags Chatbot adalah sistem chatbot cerdas berbasis RAG (Retrieval-Augmented Generation) yang dirancang untuk memberikan informasi akurat tentang usaha/bisnis di Balikpapan, Kalimantan Timur.

🎯 Tujuan Sistem

  • Menyediakan informasi bisnis secara real-time melalui natural language queries
  • Menggunakan RAG untuk pencarian semantik yang lebih akurat
  • Auto-sync dengan database untuk data terbaru
  • Mendukung berbagai jenis query (informasi, filtering, counting)

🔑 Key Technologies

Data Flow

📊 Database → RAG Pipeline

  1. Data Source: PostgreSQL database with usaha_llm view
  2. Indexing: Data transformed to text & embedded using Sentence Transformers
  3. Storage: Embeddings stored in FAISS index for fast retrieval
  4. Auto-sync: Timestamp-based synchronization every 5 minutes
  5. Search: Query embedded & matched against index using cosine similarity

🧩 Core Components

1. FastAPI Application (app/main.py)

Entry point aplikasi yang mengelola:

  • Startup & shutdown lifecycle
  • Database connection pooling
  • RAG service initialization
  • CORS configuration
  • Route registration

2. Chatbot Service (app/chatbot_service.py)

Responsibilities:

  • Query Validation: Mengecek apakah query valid & jelas
  • Intent Classification: Menentukan jenis query (info, count, filter)
  • Context Retrieval: Mendapatkan data relevan via RAG atau database
  • LLM Integration: Generate natural language response
  • Response Formatting: Strukturkan response dengan sources 
class ChatbotService:
    async def process_query(query: str) -> dict:
        # 1. Validate query
        if not is_valid_query(query):
            return {"response": "Mohon berikan query yang lebih spesifik"}
        
        # 2. Classify intent
        if is_counting_query(query):
            return await handle_counting(query)
        elif is_filtering_query(query):
            return await handle_filtering(query)
        
        # 3. RAG search
        results = await rag_service.search(query, top_k=5)
        
        # 4. Generate response
        context = rag_service.format_context(results)
        response = await generate_response(query, context)
        
        return {"response": response, "sources": results}

3. RAG Service (app/rag_service.py)

Key Features:

  • Document Indexing: Transform business data to embeddings
  • Semantic Search: Find similar businesses using vector similarity
  • Auto-sync: Incremental updates from database
  • Relevance Filtering: Threshold-based result filtering

4. Database Layer (app/database.py)

Mengelola semua interaksi dengan PostgreSQL:

  • Connection pooling (asyncpg)
  • Business data retrieval
  • Filtering queries (status, kategori, dll)
  • CSV loading (evaluation mode)

5. Authentication (app/auth.py)

JWT-based authentication untuk secure API access

🚀 Deployment Guide

⚠️ CRITICAL: Production Checklist

  • ✅ Set EVALUATION_MODE=false
  • ✅ Generate strong JWT_SECRET_KEY
  • ✅ Configure production database URL
  • ✅ Enable HTTPS with SSL certificate
  • ✅ Setup Nginx reverse proxy
  • ✅ Use process manager (systemd/supervisor)

Quick Deploy Steps

# 1. Clone repository
git clone <repo-url>
cd capstone-ai2

# 2. Install dependencies
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt

# 3. Configure .env
EVALUATION_MODE=false
DATABASE_URL=postgresql://...
JWT_SECRET_KEY=$(openssl rand -hex 32)

# 4. Run production server
uvicorn app.main:app --host 0.0.0.0 --port 5000 --workers 4

# 5. Setup Nginx + HTTPS
sudo certbot --nginx -d your-domain.com
